## About

A fully playable **Flappy Bird clone that runs entirely in the console**, built from scratch in C++. No graphics library — just raw terminal output, real-time input handling, and a solid game loop that brings the classic mobile game to life in your command line.

---

## Features

| Feature | Description |
|---------|-------------|
| **Movement System** | Smooth gravity-based bird physics with jump mechanics |
| **Obstacle Generation** | Randomized pipe gaps for varied gameplay each run |
| **Collision Detection** | Precise boundary and pipe collision logic |
| **Score Tracking** | Real-time score counter displayed during gameplay |
| **Game Loop** | Consistent frame-rate game loop for smooth rendering |

---

## Tech Stack

- **Language:** C++
- **Concepts:** Game loop architecture, real-time input, collision detection, console rendering

## How to Run

```bash
# Clone the repository
git clone https://github.com/nataliedavidnashaat/flappy-bird-console.git
cd flappy-bird-console

# Compile
g++ -o flappy_bird main.cpp

# Run
./flappy_bird
```

---

## Controls

| Key | Action |
|-----|--------|
| `Space` | Flap / Jump |
| `Q` | Quit game |
